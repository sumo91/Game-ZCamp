# 三英雄三关卡与营地选择验收 · 2026-08-16

## 背景

项目所有者实测确认第一防线（十波）可稳定通关、作为新手关难度可接受后， commissioned 本阶段：3 英雄 × 3 关卡 + 大厅选英雄/选关卡/难度提示/通关奖励交互。任务书：`docs/mission-briefs/ZCamp-三英雄三关卡与营地选择.md`。

## 实现

### 核心（src/core，全部纯数据/纯函数）

- `hero.ts`：3 英雄（营地守望者·箭塔档案/木×1.1/盾100；机枪老兵·机枪档案/×1.0/盾50；伐木大亨·箭塔档案/×1.25/盾120）× 3 关卡（第一防线 10 波★ / 裂谷尸潮 12 波★★ / 君王亲征 15 波★★★），关卡带 `difficultyStars/difficultyLabel/enemyHint/unlockedByClearing`，冻结基线校验。
- `content.ts`：`ContentCatalog.waves` → `levelWaves: Record<LevelId, WaveDefinition[]>`；第一防线十波原样冻结；裂谷尸潮/君王亲征为独立波次表（密度上调、精英提前、脉冲更密），新增中段 Boss（37s 固定时点）；校验循环按关卡逐波核对。
- `progression.ts`（新）：解锁图纯函数——`deriveUnlockedLevels/Heroes`、`isBattleSelectionAllowed`、`deriveVictoryRewards`（通关前后对比，只报新解锁）。
- `battleConfig.ts`：`resolveBattleConfig` 接收通关集合，锁定组合抛错。
- `game.ts`：按 `battleConfig.levelId` 选择该关波次表驱动生成与 `maxWave`。

### 表现层（src/phaser）

- `lobbyUi.ts`：三卡视图模型（锁定/选中/星级/解锁条件文案）+ `decideLobbyAction` 指针合法性；记忆选择被锁时回退，无记忆时默认"下一个未通关的已解锁关卡"。
- `LobbyScene`：关卡三卡 + 英雄三卡（图元锁形、★难度、敌情条、已通关徽标、选中金边），点卡切换、点开始以当前组合开战并携带通关集合。
- `progressionStore.ts`（新）：localStorage 边界模块（`zcamp.progression.v1`），通关集合 + 英雄/关卡各自独立的记忆选择，读入时按内容目录过滤未知 id。
- `GameScene`：`init` 以通关集合校验启动配置；VICTORY 转换时 `deriveVictoryRewards` + `recordLevelClear`，结算面板新增金色奖励行（有新解锁列出，无则提示返回营地查看）；再战沿用同关卡同英雄。

## 验证（renderer = AUTO/WebGL；演示模式仅取证）

- `npm run check` 全绿：110/110 测试（新增 progression 5 项、lobbyUi 重写 5 项、content 三关时间线、heroFoundation 三英雄冻结基线）。
- 大厅像素验证：初始仅 L1/H1 可选（L2/L3/H2/H3 锁形 169/168/133/130px，选中填充 2.3 万+px，L1 星级 519px）；点锁定卡后开战仍为第一防线（阻断生效）。
- 通关链路一（第一防线·演示模式）：第 10 波 VICTORY → `clearedLevelIds:["first_defense"]` 持久化 → 返回营地 L2/H2 解锁（锁形 0px）→ 清记忆后默认选中裂谷尸潮（23207px）+ 敌情条"已通关"徽标。
- 通关链路二（裂谷尸潮·机枪老兵）：启动即 `battleLevelId=broken_valley`、护盾 50（英雄属性生效）；第 6 波检出中段冲锋领主（角 578px）；12 波 VICTORY；奖励行"通关奖励 · 解锁 《君王亲征》 与 伐木大亨 已加入营地"；持久化正确。
- 通关链路三（君王亲征·伐木大亨）：护盾 120；15 波 VICTORY；终局无新解锁时奖励行显示"防线经受住了考验…"；返回营地六卡全部解锁（锁形全 0）；刷新后持久。
- 交互记账修正（验证中发现）：点英雄卡曾连带记忆当前关卡，导致通关后回大厅默认选中刚打过的关；已改为英雄/关卡独立记账，复测通过。
- 控制台全程仅 favicon 404 与 AudioContext 自动播放提示（无手势时预期）。
