# ZCamp J3 仪式感验收（2026-08-15）

对应 Mission Brief：`docs/mission-briefs/ZCamp-Juicy体验提升总目标.md`（阶段 J3）。

## 变更范围

- `src/phaser/feedback.ts` 新增纯函数：`deriveWaveBanner`（普通/首领/最终决战三档横幅文案与颜色）、`isBossEntrance`（Boss 出场判定）；新增单测 2 组。
- `src/phaser/fx/FxDirector.ts` 新增：`waveBanner`（中央大字横幅：滑入驻留淡出）、`bossEntrance`（Boss 名牌卡：缩放砸入 + 副标题）、`countUp`（结算数字滚动，带完成回调）。
- `src/phaser/fx/SoundDirector.ts` 新增 `boss_roar` 低频咆哮。
- `GameScene`：
  - 波次开始：横幅替代原顶部小通知（消除双重提示），Boss 波/最终波分级配色与字号；
  - Boss 出生（`enemy_spawned` + tier=boss）：咆哮 + 名牌卡 + 镜头震动 + 暗红边缘闪光；
  - 胜负结算：击杀数从 0 滚动到最终值（1.1 秒），滚动期间跳过每帧文本覆盖；
  - 开局部署倒计时期间空建筑格呼吸脉冲引导（金色脉动 + 呼吸半径）。
- `src/core` 零改动。
