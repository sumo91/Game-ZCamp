# ZCamp 浮窗图标化验收（2026-08-15）

来源：项目所有者玩测反馈（三项：文字过多应图标化、底板宽度与按钮数不符、建造费用数字缺失）。对应 Mission Brief：`docs/mission-briefs/ZCamp-Juicy体验提升总目标.md`（同 commission 下的迭代）。

## 变更

- `layout.ts`：`deriveSlotActionBarBounds` 增加 `buttonCount` 参数，底板宽度自适应（N×106+10）；新增 `SLOT_BAR_BUTTON_PITCH` 常量与 `slotBarButtonCenterX` 纯函数（渲染与命中共用同一坐标源）。
- `GameScene`：
  - `PanelAction` 增加 `cost` 与 `iconKind`；五处构造点（空格建造×2、升级、改造、拆除/确认拆除）全部补齐；
  - 浮窗按钮改为**图标 + 费用行**：箭塔/木材厂用建筑 glyph，升级用绿色双箭头，改造用金币，拆除用红叉；费用行显示资源小图标 + 数字（资源不足时数字变红）；拆除确认态保留文字按钮；
  - 新增 `drawSlotBarIcon`（100×44 按钮尺寸的紧凑 glyph 集）。

## 验证

- `npm run check`：102 测试全绿（新增宽度自适应与按钮中心点测试 2 项）。
- 浏览器回归（720×1280，画布 1:1）：
  - 空格浮窗两按钮（箭塔 40 / 木材厂 60 图标+费用），底板宽度贴合两按钮；
  - 图标按钮建造木材厂成功（木材扣除正确，建造后浮窗关闭）；
  - 选中已建木材厂 → 升级/拆除双图标按钮浮窗。
