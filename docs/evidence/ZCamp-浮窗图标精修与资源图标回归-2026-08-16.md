# 浮窗图标精修与资源图标回归验收 · 2026-08-16

## 背景

上一轮将浮窗按钮的 ▲/■ 单字符 Text 字形作为 Graphics 三角形路径填充不渲染的临时替代方案（见《ZCamp-浮窗图标渲染修复验收-2026-08-16》）。玩家反馈两点：

1. ▲/■ 过于简略粗糙，不足以代表「箭塔」「木材厂」；
2. 消耗行只剩数字（50 / 10），资源类型图标（原木/金币）再次缺失，无法区分木材与金币消耗。

## 结论

两项均已修复并验证。核心思路：**放弃 Text 字形，回到 Graphics，但严格只用已验证稳定渲染的图元**（fillRect / fillCircle / strokeCircle / lineBetween），继续回避有缺陷的路径填充（fillTriangle / fillPoints）。此前资源栏、改造弹窗消耗图标已长期用这组图元稳定渲染，属于同一管线的既有证据。

## 实现（src/phaser/GameScene.ts）

- `slotBarGlyphs: Text[]` → `slotBarIcons: Phaser.GameObjects.Graphics[]`，每按钮一个 Graphics（create 期创建，depth 19）。
- `drawSlotBarIcon(graphics, kind, x, y, available)` 重写为图元组合，配色对齐场上建筑美术：
  - `arrow_tower`：灰石基座 + 金色塔身 + 顶部三齿城垛 + 深色射孔 + 一根奶油色斜向箭矢（对齐场上箭塔的金三角+奶油箭线特征）。
  - `lumberyard`：棕色板条木屋（两条木板缝）+ 深色门 + 绿色人字屋顶轮廓（3 条粗线）+ 右侧橙色原木端面圆（对齐场上绿顶+橙原木特征）。
  - `upgrade`：绿色双层 V 形箭头（下层半透明）。
  - `transform`：金色圆徽 + 深色内环 + 中心亮点 + 两颗侧点。
  - `destroy`：红色粗 X。
- 消耗行：`drawResourceIcon(icon, resource, centerX-13, centerY+13, 0.62)` 接回，数字右移至 `centerX-2`。资源图标与本体图标共用同一 Graphics。
- `drawResourceIcon` 不再自带 `graphics.clear()`（会连带清掉本体图标），改由调用方负责：`renderResourceIcons` 与改造弹窗 costIcon 处已显式 clear。
- 脏检查 `slotBarRenderKey` 保留；不可用态整体 alpha 0.7、图元 alpha 0.55。拆除确认分支将图标 clear 后显示文字按钮。
- DEV 调试钩子 `__zcampSlotBar.icons` 上报 `{ visible, commands }`。

## 遗留（不变）

动态层路径填充缺陷（主城屋顶、箭塔/寒霜塔顶、Boss 头盔、精英肩甲的 fillTriangle）仍未渲染，属 Phaser 4.2.1 引擎问题；候选后续：升级 Phaser 小版本验证，或同样迁移到图元组合/Shape 管线。
