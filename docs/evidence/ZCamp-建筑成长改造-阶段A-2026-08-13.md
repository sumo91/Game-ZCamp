# ZCamp 建筑成长改造阶段 A 验收记录

日期：2026-08-13

## 交付范围

- `src/core/buildingGrowth.ts` 建立新版建筑、塔型、五级费用、四种十金币改造路线、词条池与校验器。
- 修复旧卡牌与新版成长建筑的模型互斥：旧卡牌只能作用于 `legacy_card`；growth 木材厂和改造后的 growth 特殊塔均拒绝同名旧卡牌，失败不扣费、不消耗手牌、不改等级。
- 内容校验由首批词条 pool/source 归属注册表派生，并严格限制可建定义只有 `arrow_tower` 与 `lumberyard`。
- `GameState` 增加单建筑 `traits` 和 `pendingTraitDraft`；`GamePhase.TRAIT_DRAFT` 表达升级后的强制三选一冻结状态。
- `GameSimulation` 增加 `build_building`、`upgrade_building`、`choose_building_trait`、`transform_tower` 命令。新建筑以 `model: "growth"` 双轨承载，旧卡牌系统和旧公开 UI 未切换。
- 词条抽取仅在核心使用种子随机；失败路径在扣木材/金币或推进随机状态前返回；相同种子和命令序列可重现相同三选一。
