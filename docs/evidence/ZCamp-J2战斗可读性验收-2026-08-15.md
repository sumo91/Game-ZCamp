# ZCamp J2 战斗可读性验收（2026-08-15）

对应 Mission Brief：`docs/mission-briefs/ZCamp-Juicy体验提升总目标.md`（阶段 J2）。

## 变更范围

- `src/phaser/feedback.ts` 新增纯函数：`mapTowerProjectileStyle`（塔型→弹道语言）、`shouldShowDamageNumber`（≥15 伤害才显示数字）、`coinFlightLabel`（≥1 金币才带文字）；新增单测 3 组。
- `src/phaser/fx/FxDirector.ts` 新增：`floatText`（伤害/金币漂浮文字，自毁）、`flyCoin`（金币圆点飞向资源栏）。
- `GameScene`：
  - 弹道按塔型差异化：箭塔/机枪拖尾直线、炮塔抛物线弹道 + 溅射扩散圈、电磁塔锯齿闪电链（按敌人 ID 确定性抖动）、冰冻塔冰晶线；
  - 敌人死亡改为六向爆散 + 扩散环；击杀金币飞向金币计数器（大额奖励带 +N 文字）；
  - 城墙受击时在受击车道闪现红色标记（0.3 秒）；
  - Boss 在场时顶部显示大血条 + 名称与剩余生命（`bossNameText` + dynamic 绘制）。
- `src/core` 零改动。

## 检查结果

- `npm run check`：typecheck 通过，90 个测试全过（feedback 13 项）。
- 运行时验证（Vite dev + 浏览器 720×1280，`?stage4-demo=1` 演示模式 30 倍速 + 只读 `__zcampDebug` 交叉验证）：
  - 演示模式全流程跑完 10 波 → `VICTORY`（最终 Boss 被英雄击破），无崩溃、无错误浮层；
  - 精确定格第 5 波（战斗时间 286.2s，`TACTICAL_PAUSE`，124 敌存活）：冲锋领主出生 279.5s，处于存活窗口，血条渲染路径已执行；
  - 正常速度下大厅→战斗→建造→暂停→升级→词条流程在 J1 验证中已覆盖，本轮改动未改变这些路径。

## 限制与遗留

- 弹道、爆散、金币飞行、车道标记均为瞬时动效，静态截图只能证明代码路径执行（状态交叉验证），节奏与观感需人工玩测；
- 演示模式下城墙血量被强制保持满值，城墙受击的车道标记在演示模式不可复现，验证依赖代码审查与正常模式玩测；
- Boss 出场演出（压暗 + 名牌）属 J3 范围，本阶段血条为常驻显示。
