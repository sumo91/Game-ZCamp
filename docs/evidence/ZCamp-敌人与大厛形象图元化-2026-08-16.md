# 敌人与大厅形象图元化验收 · 2026-08-16

## 背景

前序图元化（浮窗图标、场上建筑）完成后，代码中仅剩的路径填充调用为：Boss 双角、精英肩甲（`drawEnemy`），以及大厅英雄头像的金三角屋顶（`LobbyScene.heroGlyph`，同缺陷、从未渲染）。本次全部替换为稳定图元，`fillTriangle`/`fx/draw.ts` 自此无任何使用方并删除。

## 改动

- **Boss 双角**（src/phaser/GameScene.ts `drawEnemy`）：两段锥形笔画（粗段 6px + 细尖 3px）左右对称，深棕 `0x482c25`，替换两处 `fillTriangle`。
- **精英肩甲**：橙色圆肩甲 `0xd98b31`（r6）+ 深色描边 `0x8a5216`，左右各一，替换两处 `fillTriangle`。
- **大厅英雄头像**（src/phaser/LobbyScene.ts）：金色堡垒（塔身+浅金高光+三齿城垛+深色圆门），与场上主城新形象同构，替换从未渲染的金三角。
- 删除 `src/phaser/fx/draw.ts`（fillPoints 辅助已无调用方）；GameScene/LobbyScene 移除对应 import。
