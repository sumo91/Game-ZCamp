# 场上建筑形象图元化验收 · 2026-08-16

## 背景

玩家反馈：希望格子里的建筑形象与浮窗新图标（图元组合风格）统一。此前场上建筑的屋顶/顶尖全部走 `fillTriangle` 路径填充——受 Phaser 4.2.1 缺陷影响从未渲染（见《ZCamp-浮窗图标渲染修复验收-2026-08-16》），实际画面只剩石座圆+门/箭线等零散细节。

## 改动（src/phaser/GameScene.ts）

所有建筑形象改为与浮窗图标同一套「矩形/圆/线条」图元语言，配色互相呼应：

- **箭塔**（`drawTowerGlyph` 默认分支）：金色矩形塔身 + 白色高光条 + 顶部三齿城垛 + 深色射孔 + 斜向上箭矢（杆+双倒钩），与浮窗 arrow_tower 图标同构放大。
- **木材厂**（`drawBuilding`）：棕色板条木屋（两条板缝）+ 深色门 + 绿色人字屋脊（3 条粗线，含檐口线）+ 三根橙色原木端面（左二右一，带年轮圆环）。
- **主城**：金色矩形堡垒 + 浅金高光条 + 三齿城垛 + 深色圆门 + 金色檐线（替换从未渲染的金三角屋顶）。
- **寒霜塔**：六芒雪花——浅蓝圆核 + 三组交叉辐条 + 中心亮点 + 底座条（替换从未渲染的尖顶三角）。
- **机枪/火炮/电磁塔**：原本即图元画法，保持不变。
- **改造弹窗**：`drawTowerGlyph` 改传深色剪影色（`0x2c3a2f`），塔身从同色底圆中显现（此前同色叠同色，剪影不可见）。

剩余 `fillTriangle` 调用仅存敌人形象（Boss 双角、精英肩甲），不属本次范围。

## 验证（renderer = AUTO/WebGL）

- `tsc --noEmit` 无错误；vitest 102/102 通过。
- 实机建造箭塔（r0c1）+ 木材厂（r0c3）并截图（`zcamp-map-buildings-primitive-art.png`）：视觉模型逐项确认——箭塔塔身/三齿城垛/箭矢「有」，木材厂板条木屋/绿色三角屋脊/深色门/带环原木「有」，主城金色堡垒（城垛+高光+圆门）「有」；三座建筑顶部结构均实际渲染，不再只有底座圆+悬空细节。扣费正确（木 120→20，金扣 60）。
- 改造弹窗截图（`zcamp-transform-modal-silhouettes.png`）：三个选项彩色圆底内的深色剪影完整可见，可分辨机枪/火炮/雪花三种形象，金币消耗图标+数字正常。

## 遗留

- 敌人形象的路径填充（Boss 双角、精英肩甲）仍不渲染，待后续同样图元化或升级 Phaser 后统一处理。
- 建筑等级条（底部 4px 金条）为既有实现，本项未改动。
