# 大厅质感升级（皇室战争向）验收 · 2026-08-16

## 背景

氛围版（见《大厅氛围与出战预览》）获反馈："还是太偏纯绿色线框图，质感要更接近皇室战争"。目标：从"平面线框"升级到"实体卡通物件感"——这正是 Art Bible"粗轮廓、大块面、两档明暗"支柱的落实。

## 实现（LobbyScene 表现层重构，逻辑不动）

- **材质体系**：新增木料色板（`WOOD`：基色/受光/背光/厚描边/选中态）与绶带色板（关卡按难度绿→蓝→紫，借用稀有度语言；英雄按定位绿/钢蓝/棕金）。所有面板走统一 `drawBevel`：**投影 + 基色 + 上半受光 + 厚描边 + 顶部高光线**——两档明暗的块面感。
- **夜空**：纯绿底改为深靛蓝→蓝绿的 8 段夜空渐层 + **月亮**（本体/环形山/光晕）+ **15 颗星**（其中 4 颗呼吸闪烁）+ 冷/暖氛围光斑。
- **卡片 CR 化**：木框卡 + 投影 + 难度色**绶带**（带绶带尾与描边，★ 和定位字压在绶带上）+ 粗体描边标题；锁定卡保留可读标题 + 半透明暗罩 + 锁形。按压时卡片下沉 3px 回弹。
- **出征按钮实体化**：三层结构（投影 + 木质基座 + 金色 5px 厚描边 + 受光顶面）+ 按下整体物理下沉 4px；两侧**火盆**（石碗 + 火焰 + 呼吸光晕 + 火苗形变）压阵暖光。按钮收窄为 560 宽，火盆真正悬于两侧。
- **预览横幅/神器胶囊**：同套 bevel 材质；场景条外加暗色内嵌窗（inset 阴影+描边）；英雄头像底座加投影与双环。
- 文字全面加粗加描边（标题 8px、正文 2-3px 深色描边），段落标题带金色分隔线。

## 第二轮（同日）：光照背景、画窗卡片与挤出式按钮

项目所有者对照皇室战争参考图追加三点要求：背景要有底纹与光照感；关卡/英雄卡要有"图片内容"而不是一块板；主按钮立体感要强。已实现：

- **背景光照**：全屏斜纹编织底纹（明暗两组对角线条纹，极低透明度）；从标题后方扇形展开的 4 道**上帝光束**（64px 宽暖光线条）；标题后 4 层同心圆径向光晕。
- **卡片画窗化**：卡高增至 164，上部 180×98 **画窗**承载每张卡专属插画——第一防线（青空+太阳+草地+木栅栏+哨塔）、裂谷尸潮（赭石天+髑髅+双层峡谷折线+仙人掌）、君王亲征（紫夜空+星月+双塔灯火）、守望者（草丘+金堡+旗）、机枪老兵（碉堡+双炮管+沙袋阵）、伐木大亨（原木金字塔+树桩斧）；底部难度色**名牌绶带**（带尾坠）承载卡名，左上角徽章药丸（★数/定位），锁定卡画窗压暗+居中锁形。
- **挤出式主按钮**：黑色投影 + 深金侧边基座（100px 厚）+ 亮金顶面 + 顶面高光条 + 白字重描边；按下时顶面整体下沉 8px 再回弹，物理感明确；两侧火盆保留。
- 验证：110 测试全绿；像素实证 L1 天空 4237px/草地 5956px、L3 紫夜空 4316px、守望者金堡 1071px、伐木大亨原木 1459px、按钮亮金顶面 30116px+深金侧边 10222px、L1 绿绶带 2272px；交互回归（选 L1+机枪老兵→开战，护盾 50 正确）。截图 `zcamp-lobby-v4-card-art.png`。

## 第三轮（同日）：视觉 QA 修复

对最终截图做挑剔级视觉走查，发现并修复五处细节：星与月光晕过近（移星）；L1 插画哨塔与太阳拥挤（移太阳，过程中一度移到徽章药丸下方被遮挡，复测发现后改放药丸与哨塔之间的空档并像素复核 (227,215,159)）；帐篷与栅栏线重叠（栅栏立柱跳过帐篷跨度并断开横轨，帐篷层次在前）；徽章药丸贴卡框（内移 3px）；地平线亮边易误读为缝隙（透明度 0.9→0.55）。交互与 110 项测试复测通过。截图 `zcamp-lobby-v5-qa-final.png`。

## 第四轮（同日）：剪影显形与文字避让

用户反馈三处：横条夹字、底部"纯绿区域中的孤立火堆"含义不明。定位：①上一轮改版把剪影带背景与剪影形状误用同一颜色（SILHOUETTE 叠 SILHOUETTE），栅栏/塔/帐篷全部隐形，只剩篝火与亮窗可见；②信息文字被按钮底部阴影与剪影带上沿夹在窄缝中。修复：剪影带地面改浅一档（0x16281d）使剪影显形；帐篷向篝火聚拢（340/560）成组，读作"营地夜景"；横轨合并为一条全宽线；信息文字上移至按钮上方干净区（y896）。像素复核：塔身/栅栏/帐篷深色落于浅色地面、亮窗与篝火保留、旧位置文字清空。截图 `zcamp-lobby-v6-camp-visible.png`。
