## 1. 改造目标

### 1.1 需要解决的问题

当前动态手牌把多种语义放进同一张牌：

- 获得建造机会；
- 决定建筑类型；
- 升级已有建筑；
- 使用永久强化；
- 使用战术能力；
- 占用、等待和弃置手牌。

这导致基础经营行为受到随机供牌限制，也导致同一张建筑牌在“可以升级但不能新建”等情况下难以用清楚的视觉语言表达。

### 1.2 新核心原则

本阶段将三个系统职责彻底分开：

| 系统 | 玩家付出的资源 | 玩家得到的结果 | 是否随机 |
|---|---:|---|---|
| 建造 | 木材 | 在空格建造箭塔或木材厂 | 否 |
| 升级 | 木材 | 当前建筑提升等级和基础属性 | 基础成长不随机 |
| 升级词条 | 升级附带，不另收费 | 三选一词条，只作用于当前建筑 | 是 |
| 改造 | 金币 | 箭塔确定性变为指定特殊塔 | 否 |

一句话职责：

> 木材负责经营，金币负责策略，升级词条负责用随机性消解重复成长的无聊。

## 2. 本阶段玩家循环

```text
点击空格
  ↓
消耗木材建造箭塔或木材厂
  ↓
点击已有建筑
  ├─ 消耗木材升级
  │      ↓
  │   基础属性提高
  │      ↓
  │   游戏冻结并弹出该建筑词条三选一
  │      ↓
  │   选择一个，永久附加到该建筑
  │
  └─ 若为箭塔：消耗金币确定性改造成一种特殊塔
         ↓
      保留位置、等级和已有通用词条
         ↓
      后续继续用木材升级并获得该塔专属成长
```

玩家每次主要回答三类问题：

1. 木材用于扩建，还是培养已有建筑；
2. 金币用于把哪一座箭塔改造成哪种特殊塔；
3. 本次升级出现的三个词条中，哪一个最适合这座建筑和当前战局。

## 3. 概念与术语

### 3.1 建造

建造是把一个空格变成 Lv.1 建筑。

- 只消耗木材；
- 只允许建造箭塔或木材厂；
- 建造本身不触发三选一；
- 玩家不能直接建造特殊塔；
- 主城继续固定存在，不参与本阶段建造。

### 3.2 升级

升级是提高当前建筑等级。

- 只消耗木材；
- 提升当前建筑的确定性基础属性；
- 每次成功升级必定触发一次该建筑词条三选一；
- 词条只记录在并作用于被升级的这座建筑；
- 箭塔、特殊塔和木材厂均可升级；
- 建筑最高 Lv.5，因此每座建筑最多触发四次升级三选一。

### 3.3 改造

改造是把箭塔的战斗形态确定性地变成一种特殊塔。

- 只消耗金币；
- 不改变建筑等级；
- 不触发三选一；
- 不随机决定结果；
- 保留已有通用词条；
- 改造完成后不能再次改造成其他塔型；
- 特殊塔仍可继续消耗木材升级。

禁止在界面、文案和代码命令中把“升级”和“改造”混为同一概念。

## 4. 建筑体系

### 4.1 本阶段可建建筑

| 建筑 | 建造方式 | 建造资源 | 主要职责 |
|---|---|---:|---|
| 箭塔 | 空格直接建造 | 木材 | 基础单体防御，也是所有特殊塔的改造前身 |
| 木材厂 | 空格直接建造 | 木材 | 持续生产木材 |

旧版工程/修理建筑不进入本阶段新主循环，不出现在建造面板中。城墙保持当前固定系统，不因此获得新建造、升级或维修入口。

### 4.2 箭塔

箭塔必须满足：

- Lv.1 即可自动攻击；
- 定位清晰但强度低于完成改造后的特殊塔；
- 未改造时升级只从通用战斗词条池生成选项；
- 任意等级都可以改造，包括 Lv.5；
- 晚改造会获得更多通用词条，早改造会有更多机会获得特殊塔专属词条；
- 这是有意保留的改造时机策略，不额外补发专属词条。

### 4.3 特殊塔

本阶段复用现有四种特殊塔的基础攻击行为：

| 改造结果 | 核心职责 | 复用行为 |
|---|---|---|
| 机枪塔 | 快速单体输出 | 高频攻击、穿透成长 |
| 炮塔 | 范围清怪 | 爆炸伤害、燃烧成长 |
| 冰冻塔 | 减速控制 | 低伤害、减速和易伤成长 |
| 电磁塔 | 链式压制 | 多目标弹射、精英压制成长 |

改造后的等级加成必须根据新塔的基础属性重新计算。例如，Lv.3 箭塔改造为 Lv.3 炮塔后，使用“炮塔基础属性 × Lv.3 等级倍率”，而不是在箭塔最终数值上叠加炮塔数值。

### 4.4 木材厂

木材厂必须满足：

- 每座木材厂独立拥有等级和词条；
- 升级提高该木材厂的基础产量；
- 词条只改变该木材厂的产出或自身后续升级条件；
- 任何木材厂词条不得无条件直接修改其他木材厂；
- 多座木材厂的最终产量逐座结算后相加。

## 5. 首测数值基线

本节数值用于验证新循环能否成立，不是永久平衡结论。未经总制作人确认，开发不得为了“感觉更顺”自行修改。

### 5.1 开局资源

保持当前版本：

| 项目 | 数值 |
|---|---:|
| 初始木材 | 120 |
| 初始金币 | 0 |
| 主城基础木材产量 | 0.5 / 秒 |

### 5.2 建造与升级费用

| 建筑 | 建造费 | Lv.1→2 | Lv.2→3 | Lv.3→4 | Lv.4→5 |
|---|---:|---:|---:|---:|---:|
| 箭塔 | 木材 40 | 50 | 70 | 100 | 140 |
| 木材厂 | 木材 60 | 70 | 100 | 145 | 205 |

设计意图：初始 120 木材允许玩家建造一座箭塔和一座木材厂，但不能立即继续升级；随后的木材增长迫使玩家在第二座建筑和第一次升级之间取舍。

特殊塔沿用箭塔的升级费用表，不因塔型不同改变木材升级成本。本阶段先验证“培养哪一座塔”和“改造成什么”，不同时引入四套升级价格。

### 5.3 箭塔基础属性与等级成长

首测箭塔 Lv.1 基线：

| 属性 | 数值 |
|---|---:|
| 伤害 | 7 |
| 攻击间隔 | 1.0 秒 |
| 射程 | 0.60 |
| 攻击类型 | 单体 |

所有战斗塔的等级成长统一使用：

- 每提高 1 级，基于当前塔型的基础伤害增加 20%；
- 每提高 1 级，基于当前塔型的基础攻击速度增加 10%；
- 攻击间隔 = 塔型基础攻击间隔 ÷ 等级攻速倍率；
- 等级成长与词条倍率分别计算，禁止把升级永久改写进塔型基础定义。

### 5.4 木材厂基础产量

| 等级 | 基础产量 |
|---|---:|
| Lv.1 | 1.0 / 秒 |
| Lv.2 | 1.6 / 秒 |
| Lv.3 | 2.4 / 秒 |
| Lv.4 | 3.4 / 秒 |
| Lv.5 | 4.6 / 秒 |

单座木材厂最终产量：

```text
(等级基础产量 + 该厂固定加值) × 该厂产量倍率
```

总木材产速：

```text
主城基础产量 + 每座木材厂最终产量之和
```

### 5.5 改造费用

首测四种特殊塔统一使用相同价格：

| 改造结果 | 金币费用 |
|---|---:|
| 机枪塔 | 10 |
| 炮塔 | 10 |
| 冰冻塔 | 10 |
| 电磁塔 | 10 |

统一价格的目的，是先让选择集中在战术职责，而不是价格效率。当前第 1 波普通尸潮总金币约为 8.5，玩家通常需要进入第 2 波才能完成第一次改造；实际时点由击杀到账速度决定。

金币不得用于以下事项：

- 建造；
- 升级；
- 刷新词条；
- 购买额外三选一；
- 战术技能；
- 城墙操作。

## 6. 单建筑词条系统

### 6.1 归属规则

每个词条实例必须记录：

- 词条定义 ID；
- 归属建筑 ID；
- 当前层数；
- 本次获得时的建筑等级；

结算时只能从当前建筑自身读取词条。禁止继续使用旧版 `permanentApplications` 一类全局记录表达塔词条。

### 6.2 词条池规则

| 被升级建筑 | 三选一来源 |
|---|---|
| 箭塔 | 仅通用战斗词条 |
| 机枪塔 | 通用战斗词条＋机枪专属词条 |
| 炮塔 | 通用战斗词条＋炮塔专属词条 |
| 冰冻塔 | 通用战斗词条＋冰冻专属词条 |
| 电磁塔 | 通用战斗词条＋电磁专属词条 |
| 木材厂 | 仅木材厂词条 |

特殊塔升级时，三个选项中至少有一个来自本塔专属池。其余选项可以来自通用或专属池。

### 6.3 抽取规则

- 每次必须生成三个不同的词条定义；
- 选项生成后立即写入游戏状态，关闭界面、系统暂停或设备切后台都不得重新随机；
- 相同初始种子和相同命令顺序必须得到相同选项；
- 同一词条可以在不同升级中再次出现；
- 数值型词条重复获得时叠加层数；
- 机制型词条首次获得时解锁机制，重复获得时只强化其既定数值，不创建第二套触发逻辑；
- 本阶段不实现稀有度、刷新、锁定选项、重抽或保底系统；
- 当前词条池在任何合法升级场景下都必须足以生成三个不同选项。

### 6.4 首批通用战斗词条

| ID | 名称 | 单层效果 | 可重复 |
|---|---|---|---|
| `tower_damage` | 猛攻 | 该塔伤害 +12% | 是 |
| `tower_attack_speed` | 急射 | 该塔攻击速度 +15% | 是 |
| `tower_range` | 远射 | 该塔射程 +10% | 是 |
| `tower_elite_damage` | 聚能 | 该塔对精英和 Boss 伤害 +25% | 是 |
| `tower_wall_guard` | 守线 | 敌人贴墙时，该塔对其伤害 +20% | 是 |
| `tower_finisher` | 收割 | 目标生命低于 30% 时，该塔伤害 +20% | 是 |

### 6.5 首批特殊塔专属词条

| 塔型 | ID | 名称 | 单层效果 |
|---|---|---|---|
| 机枪塔 | `machine_penetration` | 穿透弹 | 穿透目标 +1；后续目标承受本次伤害的 70% |
| 机枪塔 | `machine_hunter` | 猎杀 | 对精英和 Boss 额外伤害 +30% |
| 炮塔 | `cannon_blast` | 扩爆 | 爆炸半径 +20% |
| 炮塔 | `cannon_burn` | 燃烧 | 命中使目标燃烧 3 秒，每秒造成该次基础伤害的 20% |
| 冰冻塔 | `frost_deep` | 深寒 | 该塔减速持续时间 +0.5 秒，减速倍率额外降低 0.05 |
| 冰冻塔 | `frost_vulnerability` | 冰霜标记 | 该塔对正被自己减速的目标伤害 +25% |
| 电磁塔 | `electric_chain` | 弹射 | 该塔弹射目标 +1 |
| 电磁塔 | `electric_overload` | 过载 | 该塔对精英和 Boss 伤害 +30% |

重复规则：

- 穿透弹、弹射：每层继续增加目标数；
- 猎杀、扩爆、冰霜标记、过载：数值直接叠加；冰霜标记不得放大其他塔的伤害；
- 燃烧：首次解锁，后续每层使燃烧伤害提高 50%，不增加第二个燃烧触发器；
- 深寒：持续时间和减速倍率按层叠加，但最终移动速度不得低于系统安全下限。

### 6.6 首批木材厂词条

| ID | 名称 | 单层效果 | 可重复 |
|---|---|---|---|
| `lumber_output` | 精细采伐 | 该木材厂产量 +25% | 是 |
| `lumber_flat` | 双班制 | 该木材厂固定产量 +0.4 / 秒 | 是 |
| `lumber_upgrade_discount` | 工具维护 | 该木材厂后续升级木材费 -15% | 是，折扣上限 35% |
| `lumber_wave_stockpile` | 波次储备 | 每次新波开始时，该木材厂提供木材 5 | 是 |

“波次储备”增加的是全局木材，但触发来源和层数只记录在该木材厂上；拆除该厂后不再触发。

## 7. 升级与强制三选一流程

### 7.1 成功升级的原子流程

升级命令必须一次性完成：

1. 再次检查建筑存在、等级、资源和当前阶段；
2. 扣除正确木材；
3. 建筑等级提高；
4. 更新确定性基础属性；
5. 生成三个词条选项并写入 `pendingTraitDraft`；
6. 冻结有效战斗时间；
7. 发出建筑升级和词条选择事件；
8. UI 显示强制三选一。

任一步失败时，不扣资源、不升级、不改变随机数状态。

### 7.2 暂停语义

- 从 `RUNNING` 中升级：进入战术暂停，选择完成后仍保持战术暂停；
- 从 `TACTICAL_PAUSE` 中升级：保持战术暂停；
- 从开局倒计时中升级：冻结倒计时，选择完成后恢复原开局倒计时；
- 系统暂停可以覆盖词条界面，但恢复后必须回到相同三个选项；
- `pendingTraitDraft` 存在期间不能继续战斗、再次升级、改造、建造、拆除或重新开始抽取；
- 玩家必须选择一个词条，不能关闭、取消、跳过或刷新；
- 选择词条本身不消耗时间或资源；
- 选择完成后，建筑词条立即生效。

### 7.3 待选择状态

核心状态至少需要表达：

```text
pendingTraitDraft
├─ buildingId
├─ options[3]
├─ createdAtLevel
└─ returnPhase
```

UI 不得自行保存或重新生成选项；界面只渲染核心状态。

## 8. 改造流程

### 8.1 合法条件

只有同时满足以下条件才允许改造：

- 目标建筑仍然存在；
- 目标是箭塔；
- 当前没有待处理词条三选一；
- 当前金币不少于改造价格；
- 当前阶段允许基地操作；
- 目标特殊塔定义有效。

### 8.2 成功改造

成功后：

- 扣除金币；
- 建筑 ID、格子和等级不变；
- 建筑类型改为选定特殊塔；
- 已有通用战斗词条全部保留；
- 攻击冷却按新塔攻击间隔进行安全截断，不能因改造立即多攻击或长时间失效；
- 不生成词条三选一；
- 发出独立的 `tower_transformed` 事件；
- 建筑详情立即更新为新塔属性和后续词条池说明。

失败时不扣金币、不改变建筑、不消耗随机数。

## 9. 拆除与重启

本阶段沿用当前拆除基线：

- 非主城建筑可以拆除；
- 拆除不返还木材或金币；
- 拆除建筑时，该建筑等级和全部词条一起永久消失；
- 有待选择词条时不能拆除任何建筑；
- 主城不可拆除。

重新开始一局时必须清除：

- 所有非主城建筑；
- 所有建筑词条；
- 待选择词条；
- 本局随机数进度；
- 所有旧卡牌、手牌或永久强化运行状态。

## 10. 战斗和经济结算边界

### 10.1 单塔结算

每次塔攻击必须按以下来源计算：

1. 当前特殊塔或箭塔的基础定义；
2. 当前建筑等级倍率；
3. 当前建筑自己的通用词条；
4. 当前建筑自己的塔型专属词条；
5. 目标敌人的既有防御与 Boss 规则。

禁止通过塔型 ID 查找一个全局强化次数并让所有同类塔同时获得效果。

### 10.2 木材结算

每个有效战斗步长中：

- 主城继续提供 0.5 / 秒；
- 逐座读取木材厂等级和自身词条；
- 将逐座结果相加；
- 战术暂停、强制三选一和系统暂停期间不增长；
- 主动支付木材后 UI 立即刷新，不等待下一帧资源增长。

### 10.3 金币结算

- 敌人奖励和当前波次总金币保持不变；
- 金币仍在敌人死亡时到账；
- 金币只由改造命令消耗；
- 不再存在永久卡、战术卡或额外抽取消耗金币。

## 11. 界面与交互状态

### 11.1 总体替换

底部动态手牌区替换为“所选目标的操作面板”。

正式切换后必须移除：

- 四张手牌；
- 卡牌液位；
- 下一张牌补给进度；
- 手牌等待提示；
- 弃牌与取消弃牌；
- 永久卡二次确认；
- 战术卡使用入口；
- 所有“过牌、补给、手牌已满”文案。

资源栏保留：

- 木材；
- 木材实时产速；
- 金币。

原“下一张牌”横向补给区域移除。该空间可以收回给建筑详情，不在本阶段新增另一个进度系统。

### 11.2 空格选中态

点击空格后显示：

```text
空建筑格
├─ 建造箭塔｜木材 40
└─ 建造木材厂｜木材 60
```

- 可支付按钮正常高亮；
- 不可支付按钮仍可读取名称和费用，但进入明确禁用态；
- 点击不可支付按钮只显示准确差额，不进入悬空建造模式；
- 建造成功后自动选中新建筑并切换到建筑详情。

### 11.3 建筑详情态

所有建筑详情至少显示：

- 建筑名称和等级；
- 当前职责；
- 当前核心属性；
- 下一等级提升内容；
- 下一次升级木材费用；
- 已获得词条及层数；
- 升级按钮；
- 拆除按钮。

箭塔额外显示：

- `改造`按钮；
- 四种特殊塔入口；
- 每种改造的金币费用；
- 改造后职责简述。

特殊塔详情不显示再次改造入口。

### 11.4 改造面板

改造面板是确定性选择，不使用卡牌视觉语言。四个选项必须同时表达：

- 塔型名称；
- 核心职责；
- 金币费用；
- 当前是否支付得起。

点击支付不起的塔型只给差额提示，不改变建筑状态。允许关闭改造面板返回建筑详情。

### 11.5 强制词条三选一

三选一面板必须表达：

- 被升级建筑的名称、位置和新等级；
- 三个词条名称；
- 每个词条的当前层数和选择后的效果；
- 词条是通用还是当前塔型专属；
- “选择一个以完成升级成长”的强制语义。

三选一不提供关闭、跳过、刷新或恢复战斗按钮。选择完成后回到建筑详情，并保持相应的暂停状态。

### 11.6 输入优先级

从高到低：

1. 结果结算；
2. 系统暂停；
3. 强制词条三选一；
4. 改造面板；
5. 建筑详情或空格建造；
6. 战场普通选择。

高优先级界面存在时，下层输入不得穿透。

### 12.1 内容定义

## 13. 实施阶段与门禁

本阶段使用独立功能分支，不在半完成状态下发布到 `master`。

### 13.1 阶段 A：领域模型双轨搭建

目标：建立新规则的纯核心模型，但暂不替换公开 UI。

范围：

- 新建筑定义、箭塔、升级表和改造路线；
- 单建筑词条记录；

- 待选择状态与冻结规则；
- 新建、升级、选择词条、改造命令；
- 对应核心测试。

门禁：新模型全部测试通过，旧界面仍可构建；不发布。

### 13.2 阶段 B：战斗与经济接入

目标：让新等级、词条和改造真实影响战斗与产出。

范围：

- 箭塔自动攻击；
- 四种特殊塔改造；

- 单木材厂等级与词条产出；
- 移除旧全局永久强化对结算的依赖。

门禁：证明同类建筑之间效果不串联；旧 UI 仍不发布。

### 13.3 阶段 C：界面切换

目标：用空格建造、建筑详情、改造和强制三选一完整替换手牌界面。

范围：

- 空格建造面板；
- 建筑详情；
- 升级反馈；
- 改造面板；
- 词条三选一；
- 720×1280 与 360×640 适配；
- 触摸热区和输入优先级。

门禁：从开局到至少第 3 波可完整操作新循环，无须调用任何旧卡牌入口。

### 13.4 阶段 D：旧系统清理与候选版验收

门禁：代码和玩家界面中不存在两套可操作成长系统；公开 Pages 在最终确认前保持旧版。

## 14. 自动化验收矩阵

### 14.1 建造

- 空格可建箭塔或木材厂；
- 精确费用可建，差 1 木材不可建；
- 建造只扣木材；
- 占用格、主城格和非法格不能建造；
- 建造不触发词条；
- 建造失败不改变资源、随机数或状态。

### 14.2 升级

- 各等级读取正确费用；
- 精确费用可升级，差 1 木材不可升级；
- Lv.5 不能继续升级；
- 升级提升等级和基础属性；
- 成功升级必定创建三个合法且不重复的选项；
- 升级失败不扣资源、不推进随机数；
- 升级只扣木材，不扣金币。

### 14.3 随机与暂停

- 相同种子、相同命令顺序产生相同选项；
- 选项写入状态后不会因重绘、系统暂停或恢复而变化；
- 待选择期间有效时间、敌人、资源和波次冻结；
- 待选择期间不能继续操作基地或恢复战斗；
- 只能选择三个选项之一；
- 选择完成后仍保持规定的返回阶段。

### 14.4 单建筑隔离

- A 箭塔获得猛攻后，B 箭塔伤害不变；
- A 特殊塔获得机制词条后，同类 B 塔没有该机制；
- A 木材厂获得产量词条后，B 木材厂产量不变；
- 拆除 A 后，它的词条不再产生任何效果；
- 建筑 ID 而非格子或塔型决定词条归属。

### 14.5 改造

- 箭塔可以改造成四种特殊塔；
- 改造只扣金币；
- 金币差 1 时不能改造；
- 改造保留建筑 ID、格子、等级和通用词条；
- 改造后按特殊塔基础属性重新计算等级结果；
- 改造不触发词条三选一；
- 特殊塔不能二次改造；
- 改造失败不扣金币、不推进随机数。

### 14.6 词条池

- 箭塔只出现通用词条；
- 木材厂只出现经济词条；
- 特殊塔每组三选一至少一个本塔专属词条；
- 不出现其他塔型专属词条；
- 重复机制词条只增强既有机制，不复制触发器；
- 数值层数与 UI 显示一致。

### 14.7 旧系统退出

- 新局没有手牌；
- 没有补给计时和 waiting 状态；
- 没有弃牌；
- 没有永久卡或战术卡；
- 金币除改造外没有任何消费路径；
- 最终核心状态不含旧卡牌运行字段。

## 15. 浏览器与产品验收矩阵

### 15.1 核心路径

1. 开局用 120 木材建一座箭塔和一座木材厂；
2. 等待木材增长并升级箭塔；
3. 游戏冻结并出现三个通用词条；
4. 选择一个后检查仅该箭塔变化；
5. 击杀获得金币；
6. 金币足够后将该箭塔改造成一种特殊塔；
7. 再次升级并看到至少一个本塔专属词条；
8. 另一座同类塔不继承这些词条；
9. 升级木材厂并确认产速变化来自该厂；
10. 完成后正常恢复战斗，波次和尸群行为仍与当前版本一致。

### 15.2 交互语言

- 空格只表达建造；
- 已有建筑只表达详情、升级、改造或拆除；
- 升级费用始终显示木材；
- 改造费用始终显示金币；
- 任何地方不把改造写成升级；
- 不可支付按钮在点击前已明显区别；
- 点击不可支付按钮只提示差额，不进入尴尬的悬空状态；
- 三选一明确显示作用对象为当前建筑；
- 已有词条和层数可以随时在建筑详情中查看。

### 15.3 视口和输入

- 720×1280 下所有面板、属性和三选一完整显示；
- 360×640 下不裁切费用、按钮和词条说明；
- 主要触摸目标有效高度不低于 56 设计像素；
- 模态界面不存在点击穿透；
- 战术暂停、强制词条选择和系统暂停的优先级清楚；
- 控制台无页面自身 error/warning。

### 15.4 回归边界

- 当前 60 秒波次不变；
- 当前尸群数量与脉冲不变；
- 当前城墙规则不变；
- 当前 Boss 和胜负条件不变；
- 建造和词条操作在战术暂停中可用；
- 暂停期间资源、敌人和波次仍冻结。

## 17. 成功判断

本阶段成功不以内容数量判断，而以以下问题判断：

1. 玩家是否能够不依赖随机供牌，明确执行建造和升级计划；
2. 玩家是否清楚区分木材升级与金币改造；
3. 玩家是否会因为单建筑词条不同而关心“培养哪一座建筑”；
4. 早改造和晚改造是否产生可理解的策略差异；
5. 两座同类塔是否能形成肉眼可辨识的不同成长经历；
6. 新循环是否在不改变现有尸潮、城墙和波次的情况下完整运行；
7. 玩家是否认为新循环比动态手牌更清晰、更可控，同时仍有足够随机变化。

只有以上核心问题经本地候选版和 QA 证明成立后，才进入完整词条、主城、挑战、城墙和波次结构的下一阶段讨论。

## 18. 已确认的首测冻结基线

以下内容已由项目所有者确认，视为首测冻结基线：

1. 建筑最高 Lv.5，每次升级都触发一次强制三选一；
2. 箭塔和特殊塔共享同一套升级木材费用；
3. 四种特殊塔统一消耗 10 金币改造；
4. 特殊塔升级三选一至少包含一个本塔专属词条；
5. 任意等级均可改造，改造不补发过去等级的专属词条；
6. 木材厂也通过升级获得只作用于自身的随机词条；
7. 工程/修理建筑、全局永久卡和战术卡退出本阶段；
8. 词条选择不可取消、跳过或刷新；
9. 当前 60 秒波次、尸群、城墙和地图完全冻结；
10. 使用四阶段开发门禁，最终候选通过前不更新公开 `master`。
