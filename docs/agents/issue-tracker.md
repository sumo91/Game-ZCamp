# Issue tracker

Issues and specs live in GitHub Issues for sumo91/Game-ZCamp.
Use gh with --repo sumo91/Game-ZCamp.

Create issues using --title and --body-file.
Write multiline bodies to a UTF-8 file before publishing.
Read issues with gh issue view; list them with gh issue list.
Apply or remove labels with gh issue edit.

When a skill says publish to the issue tracker, create a GitHub issue.
When a skill says fetch a ticket, read the corresponding GitHub issue.

PRs as a request surface: no.
